# 우리 반 역할분담 (Classroom Role Assigner)

초등학교 교실에서 학생 20명의 1인 1역할을 공정하고 투명하게 배정하고, 정원 불일치·중복·누락 오류를 원천 차단하는 순수 HTML/CSS/JS 정적 웹 애플리케이션 구현 계획입니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 사전 질의응답을 통해 확정된 핵심 규칙 및 설계 결정사항입니다.

- **기본 역할 및 정원 (확정)**: 기본 6개 역할(총 정원 20명)을 제공하며, 교사가 필요에 따라 역할을 추가/삭제하거나 정원 숫자를 조절할 수 있습니다.
  - 1인 1역 기본 6개 역할:
    1. 칠판 도우미 (2명)
    2. 급식 도우미 (4명)
    3. 환경 도우미 (4명)
    4. 학습 도우미 (4명)
    5. 체육 도우미 (3명)
    6. 방송 도우미 (3명)
    (합계: 20명)
- **스프레드시트 연동 전 초기 동작 (확정)**: 구글 스프레드시트/Apps Script Web App URL이 없더라도, 기본 내장 가상 학생 20명(`S01`~`S20`, `가상01`~`가상20`)으로 즉시 배정 및 모든 기능을 테스트할 수 있습니다.
- **직전 역할 기록 처리 (확정)**: [결과 확정] 시 현재 화면의 역할 결과가 '직전 역할'로 기록되며, 재배정 시에는 학생들의 이전 역할을 화면에 참고용으로 표시하되, 배정 알고리즘 자체는 완전 무작위(Fair Random)로 배정합니다.
- **기술적 경계 (준수)**: 프레임워크(React, Vue 등), 번들러(Vite, Webpack), Node.js 서버, 외부 라이브러리 없이 오직 `index.html`, `style.css`, `app.js` 3개 파일(상대 경로 `./`)로만 빌드하며, 구글 스프레드시트 연동용 스크립트는 `Code.gs`로, 사용 가이드는 `setup.md`로 제공합니다.

## 1. Overview & Core Concept

- **주요 기능**:
  - 학생 참여 선택 (전체 선택/개별 체크)
  - 역할 목록 관리 및 역할별 정원 증감
  - 실시간 정원 일치 검증 (참여 인원 == 역할 정원 합계)
  - 편향 없는 공정한 무작위 셔플 배정 (Fisher-Yates) 및 자동 중복·누락 무결성 검증
  - 배정 결과 확정 (직전 역할 비교 뱃지 갱신)
  - 배정표 인쇄(A4 가로/세로 최적화 CSS) 및 CSV(UTF-8 BOM) 다운로드
  - 구글 스프레드시트/Apps Script 연동 모달 (URL 입력 및 데이터 불러오기)
- **주 사용자**: 초등학교 담임교사
- **핵심 가치**:
  - 복잡한 수작업 배정표 작성 시간 단축 (수초 이내 완료)
  - 학생 이름, 성별 등 선입견을 원천 배제한 학생ID 기반의 공정한 추첨
  - 한눈에 보이는 중복/누락 0% 무결성 보장

## 2. User Experience & Visual Design

### 키 사용자 플로우
1. **진입**: 앱 접속 시 기본 가상 학생 20명과 기본 6개 역할(정원 합계 20명)이 로드되고, 상단에 `참여 20명 = 정원 20명 (배정 가능)` 녹색 배지 표시.
2. **조정 (선택 사항)**: 결석생 체크 해제 시 인원 불일치 경고 배지(`참여 19명 ≠ 정원 20명 (-1명 차이)`)가 나타나며 배정 버튼이 비활성화됨. 역할 정원을 1명 줄이면 다시 배정 가능 상태로 전환.
3. **자동 배정**: [역할 자동 배정] 버튼 클릭 $\to$ 셔플 애니메이션 후 우측 그리드에 역할별 배정 학생 카드가 깔끔하게 정렬되고, 상단에 '중복 0건, 누락 0건' 무결성 검증 결과 표시.
4. **결과 확정**: [결과 확정] 클릭 $\to$ 현재 배정 결과가 '직전 역할'로 브라우저 메모리에 저장됨. 이후 다시 배정 시 각 학생 카드에 `(직전: 급식 도우미)` 라벨이 함께 표시되어 비교 용이.
5. **내보내기**:
   - [CSV 저장]: 교무업무 및 엑셀 확인용 CSV 파일 즉시 다운로드.
   - [인쇄하기]: 브라우저 인쇄 창이 열리며, 불필요한 버튼/설정창이 숨겨지고 학급 역할분담표 서식만 깔끔하게 출력.

### 비주얼 아이덴티티 및 디자인 원칙
- **스타일**: 따뜻하고 단정한 에듀테크 감성의 클린 인터페이스.
- **색상 체계 (60-30-10 규칙)**:
  - 60% 캔버스: 부드러운 소프트 아이보리/슬레이트 (`#F8FAFC`, `#FFFFFF`)
  - 30% 구조 표면: 절제된 카드 배경, 연한 구분선 (`#E2E8F0`), 명도 높은 텍스트 (`#1E293B`, `#475569`)
  - 10% 강조색: 교육용 신뢰 블루 (`#2563EB`) 및 배정 준비 완료 에메랄드 (`#059669`), 경고 앰버 (`#D97706`)
- **타이포그래피**: 시스템 폰트 스택 (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Noto Sans KR", sans-serif`)으로 별도 웹폰트 로딩 지연 없는 빠른 반응성. 숫자에는 고정폭 `tabular-nums` 적용.
- **접근성 및 제로 필 원칙**: 불필요한 장식용 캡슐이나 네온 효과를 배제하고, 기능 버튼과 상태 정보를 명확한 텍스트와 보조 아이콘으로 표현.

## 3. Key Product Decisions & Trade-Offs

| 결정 사항 | 선택한 방식 | 선택 이유 | 대안 및 탈락 이유 |
| :--- | :--- | :--- | :--- |
| **프론트엔드 기술 스택** | 순수 HTML5 + Vanilla CSS3 + ES6 JS | GitHub Pages에 별도 빌드/배포 파이프라인 없이 파일 3개로 직접 호스팅 가능 | React/Vite: 번들러 및 종속성 관리 복잡도로 인해 비개발자 교사 유지보수 난이도 급증 |
| **개인정보 보호** | 화면에 `학생ID`(S01~S20)와 `이름`(가상01~가상20)만 노출 | 교실 빔프로젝터 투사 시 학생들의 실제 성명·성별 노출 위험 차단 | 실명/성별 노출: 개인정보보호법 및 선입견 없는 무작위 배정 취지에 위배 |
| **데이터 저장 방식** | 읽기 전용 Apps Script GET API + 로컬 세션 보존 | 스프레드시트에 임의 쓰기를 허용하지 않아 원본 명부 훼손 위험 차단 | 양방향 실시간 동기화: 동시 접속 충돌 및 쓰기 권한 누출 보안 리스크 존재 |
| **직전 역할 기록** | 브라우저 세션(화면 상태)에만 갱신 보존 | 요구사항: "확정은 현재 화면의 직전 역할 기록만 갱신한다. 시트에 쓰지 않는다" 충족 | 구글 시트 저장: 요구사항 위배 및 시트 오염 유발 |

## 4. Technical Architecture & Data Strategy

### 시스템 구조도 (System Architecture)

```
┌────────────────────────────────────────────────────────────────────────┐
│                          index.html (UI View)                          │
├────────────────────────────────────────────────────────────────────────┤
│  [상단] 앱 제목 · 자료 출처 (기본/구글시트) · 참여 인원 / 정원 카운터   │
├───────────────────────────────────┬────────────────────────────────────┤
│  [왼쪽] 설정 패널                 │  [오른쪽] 배정 결과 그리드         │
│  - 참여 학생 체크리스트 (S01~S20) │  - 역할별 카드 (정원/배정 학생 목록)│
│  - 역할 및 정원 설정 (증감/추가)  │  - 직전 역할 비교 태그             │
├───────────────────────────────────┴────────────────────────────────────┤
│  [하단] 실행 툴바: [역할 자동 배정] · [결과 확정] · [CSV 저장] · [인쇄하기]│
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                         DOM Event Handling & State
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                             app.js (Logic)                             │
├────────────────────────────────────────────────────────────────────────┤
│  • AppState: students[], roles[], previousAssignments{}, isAssigned    │
│  • Validation: checkTotalQuota() (참여인원 == 정원합계 검증)           │
│  • Assignment: fisherYatesShuffle() -> Slice by quota -> IntegrityCheck│
│  • Confirm: update previousAssignments in memory                       │
│  • Exporters: exportToCsv() (UTF-8 BOM), printAssignment()             │
│  • Sheet Fetcher: fetchFromGoogleSheet(webAppUrl)                      │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ (선택 연동 시 GET fetch)
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        Google Apps Script (Code.gs)                    │
├────────────────────────────────────────────────────────────────────────┤
│  • doGet(e): 구글 시트 '학생' 탭 읽기                                  │
│  • 열 스키마: 학생ID | 이름 | 성명 | 성별                              │
│  • Privacy Filter: [학생ID, 이름]만 JSON 반환 (성명, 성별 제외 필터링)│
└────────────────────────────────────────────────────────────────────────┘
```

### 파일 구성 (Files Deliverables)
1. `index.html`: 시맨틱 HTML 구조, 시트 연동 모달, 직관적인 3단 레이아웃.
2. `style.css`: 에듀테크 최적화 모던 CSS, flexbox/grid 레이아웃, 인쇄용 `@media print` 스타일.
3. `app.js`: 무작위 셔플, 중복/누락 검증, 인원 수 불일치 차단, CSV 내보내기, Apps Script 통신.
4. `Code.gs`: 구글 스프레드시트 Apps Script 소스코드 (개인정보 제외 필터링 적용).
5. `setup.md`: 구글 스프레드시트 작성법(시트이름 `학생`, 열 구조) 및 Apps Script 웹앱 배포 가이드.

### 데이터 검증 및 무결성 로직
- **배정 전 조건**:
  - `activeStudentCount === totalRoleQuota` $\to$ 불일치 시 배정 실행 차단 및 인원 차이 UI 경고.
  - `activeStudentCount > 0` $\to$ 0명일 때 오류 안내.
- **배정 알고리즘**:
  1. 참여 학생 ID 목록 추출: `let pool = [...activeStudents];`
  2. Fisher-Yates 무작위 셔플 수행.
  3. 역할별 정원(`quota`)만큼 슬라이싱하여 각 역할에 배정.
  4. **무결성 사후 검증 (Automated Integrity Check)**:
     - 중복 검사: 배정된 모든 학생 ID를 `Set`에 추가하며 중복 발생 여부 검사 (`assignedSet.size === totalAssigned`).
     - 누락 검사: 참여 학생 중 배정되지 않은 학생이 있는지 대조 (`activeStudents.every(id => assignedSet.has(id))`).
     - 결과 요약 텍스트를 UI에 표시하여 교사가 신뢰할 수 있도록 보장.

## 5. 직접 실행할 단계별 검사 시나리오

1. **정상 시나리오 (20명 참여, 정원 20명)**:
   - 앱 로드 직후 [역할 자동 배정] 클릭.
   - 결과: 6개 역할에 20명이 빈틈없이 1명씩 배정되며 "중복 0건, 누락 0건 (20/20 배정 완료)" 배지 출력 확인.
2. **예외 시나리오 1 (인원 불일치 차단)**:
   - 학생 1명을 체크 해제 (참여 19명, 정원 20명).
   - 결과: [역할 자동 배정] 버튼이 즉시 비활성화(`disabled`)되고, "참여 인원(19명)과 역할 정원(20명)이 맞지 않습니다. (1명 부족)" 메시지 노출 확인.
3. **예외 시나리오 2 (정원 초과 차단)**:
   - 역할 정원 하나를 1 증가시켜 정원 합계를 21명으로 변경.
   - 결과: "1명 초과" 경고 및 배정 버튼 비활성화 유지 확인.
4. **확정 및 재배정 구분 검사**:
   - 20명 정상 배정 후 [결과 확정] 클릭.
   - 다시 [역할 자동 배정] 클릭.
   - 결과: 새로 배정된 학생 태그 옆에 `(직전: OOO)` 텍스트가 표시되어 이전 확정 기록과 명확히 구분되는지 확인.
5. **CSV 및 인쇄 검사**:
   - [CSV 저장] 클릭 $\to$ 다운로드된 `.csv` 파일을 열었을 때 한글 깨짐 없이 `역할,학생ID,이름,직전역할`이 올바르게 나타나는지 확인.
   - [인쇄하기] 클릭 $\to$ 웹 브라우저 인쇄 미리보기에서 컨트롤 버튼, 체크박스가 감춰지고 깔끔한 표 형식으로 레이아웃되는지 확인.
